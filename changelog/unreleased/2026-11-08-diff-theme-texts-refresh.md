- **Diffs take the app's code colours, open a parsed patch's folds, and keep their state across a refresh.** `DiffView::syntax_theme` colours code with the app's `SyntaxTheme` (the one its markdown uses) instead of the kit's default. `FileDiff::with_texts(old, new)` gives a parsed file its whole texts, as `git show` reads them, so its unchanged ranges open as a diff built from texts does; a text that doesn't fit the hunks (context may differ in whitespace, for `git diff -w`) isn't kept. `DiffState::update_files` swaps in the same diff taken again, keeping each file's collapse by path and its opened ranges while they haven't moved.
